Protocol Reference

Client → Server Messages

Subscribe

type: subscribe

A request to join an element's channel to receive real-time updates.

{
"type": "subscribe",
"element_id": "..."
}

Unsubscribe

type: unsubscribe

A request to leave an element's channel to stop receiving updates.

{
"type": "unsubscribe",
"element_id": "..."
}

Publish Message

type: message_element

Sends a message from the client to the element's channel. Requires "Read/Write" (RC) permissions.

{
"type": "message_element",
"element_id": "...",
"message": { "value": 25.5 },
"auth": {
    "user_id": user_id,
    "username": username
},
"last_edit_at": 2025-10-03T18:30:57.124Z // Optional, ISO 8601 format

}

Server → Client Messages

Subscription Confirmation

type: subscribe

Confirms a successful subscription. Provides initial state, permissions, and element details.

{
"type": "subscribe",
"subscribed": true,
"permissions": "RC",
"details": { ... },
"connected": true
}

Unsubscribe Confirmation

type: unsubscribe

Confirms an unsubscription, either client-initiated or forced by the server (e.g., due to revoked permissions).

{
"type": "unsubscribe",
"unsubscribe": true,
"reason": "Permission revoked"
}

Element Message (Data)

type: message_element

The primary message for broadcasting real-time data or cached points to the browser.

{
"type": "message_element",
"message": { ... },
...
}

Permissions Update

type: permissions_update

Sent when a user's permissions for an element change (e.g., from `RC` to `R`).

{
"type": "permissions_update",
"element_id": "...",
"permissions": "R"
}

Element Connection Status

type: element_connection_status

Informs the client about the connection status of the underlying element (e.g., Node-RED connection).

{
"type": "element_connection_status",
"element_id": "...",
"connected": false
}

Error Message

type: error

Sent by the server when an error occurs, such as a malformed request or insufficient permissions.

{
"type": "error",
"error_code": "permission_denied",
...
}
